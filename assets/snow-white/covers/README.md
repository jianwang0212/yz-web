# Snow White Visual Kit

Primary page: `https://thisisyz.com/snow-white`

## Core Assets

- `cover-10-final.jpg`: primary key visual. Use for website hero, Open Graph/Twitter preview, video watermark/title card background, and the first image in social posts.
- `poster-wide-lyrics.jpg`: editorial banner. Use for article covers, video intros, long-form thumbnails, and lyric/story posts.
- `contact-sheet.jpg`: process visual. Use when talking about cover exploration, A/B testing, or behind-the-scenes design decisions.
- `cover-01-night-window.jpg` to `cover-09-spring.jpg`: cover runway variants. Use as carousel pages, video chapter cards, or supporting story images.
- `visual-01-night-window.jpg` to `visual-07-dream-closeup.jpg`: scene library. Use as editorial illustrations inside articles, video B-roll overlays, and section backgrounds.
- `square-01-night-title.jpg` to `square-06-variant.jpg`: square social variants. Use for feed thumbnails, profile-adjacent posts, and compact embeds.

## Usage Rules

- Always include the page URL in public-facing posts: `thisisyz.com/snow-white`.
- Keep the final cover as the default thumbnail unless the post is specifically about the design process.
- Pair dark night scenes with ice-blue or soft-pink text overlays; avoid adding unrelated neon colors.
- For videos, use the final cover for the opening lockup and scene-library images as chapter transitions.
- For articles, lead with `poster-wide-lyrics.jpg` or `cover-10-final.jpg`, then use the runway variants as supporting figures.
